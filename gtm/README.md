# Kontener web GTM

[Instrukcja krok po kroku](configuration-guide.md) i [kod tagów](kod-tagow.md) opisują konfigurację na kontach studentów. Tryb lokalny jest odseparowany od Cookiebot uruchamianego przez GTM. Uzupełnijcie wyłącznie rzeczywiste identyfikatory.

Do oddania dołączcie `container-published.json` uzyskany przez **Admin → Export Container** dla opublikowanej wersji z **Versions**. Zapiszcie numer i datę wersji w raporcie. Status eksportu **NOT TESTED**. [Pomoc GTM](https://support.google.com/tagmanager/answer/6106997)

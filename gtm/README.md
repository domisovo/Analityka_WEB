# Kontener web GTM

[Konfiguracja krok po kroku](configuration-guide.md) oraz [kod szablonu i tagów](kod-tagow.md) służą do zbudowania kontenera. W `strona/js/config.js` wpiszcie rzeczywisty identyfikator kontenera po skonfigurowaniu reguł. Identyfikatory GA4, Meta i Clarity są stałymi w GTM. Wszystkie pola identyfikatorów są celowo puste w projekcie startowym.

Tu należy dołączyć `container-published.json` wyeksportowany przez **Admin → Export Container** z numeru wersji widocznego jako opublikowany w **Versions**. W raporcie zapiszcie numer i datę publikacji. Instrukcja nie jest eksportem kontenera. [Pomoc GTM](https://support.google.com/tagmanager/answer/6106997)

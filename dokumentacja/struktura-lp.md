# Struktura i makieta LP

| Kolejność | Widok i funkcja |
| --- | --- |
| Nawigacja | EquiSoul, skróty do programu, organizacji i FAQ, opcja dotarcia do formularza. Na telefonie przycisk rozwija linki. |
| Hero | Zdjęcie konia, nazwa oferty, informacja o początkującym odbiorcy i CTA. |
| Korzyści | Sześć powodów udziału w trzech parach tematycznych. |
| Program | Cztery kolejne etapy z mierzoną sekcją. |
| Organizacja | Cena, miejsce, grupa, czas, doświadczenie i sprzęt. |
| Dla kogo i galeria | Obawy początkujących i zdjęcia pokazujące otoczenie zajęć. |
| FAQ | Siedem odpowiedzi rozwijanych klawiaturą lub dotykiem. |
| Końcowe CTA i formularz | Przypomnienie oferty, jeden formularz demonstracyjny i lokalne potwierdzenie. |
| Stopka | Charakter edukacyjny, narzędzia, prywatność i zmiana zgód. |

Na desktopie zdjęcie hero zajmuje całą szerokość, a treść pozostaje na lewej stronie. Program i formularz mają po dwie kolumny. Na telefonie hero, program, organizacja i formularz układają się pionowo. Ścieżka bez CTA pozostaje możliwa przez przewijanie.
